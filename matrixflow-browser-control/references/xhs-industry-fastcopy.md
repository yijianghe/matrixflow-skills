# 小红书行业快速出稿库（v1，2026-08-06）

用户说行业 → 直接从下表拼装文案（标题 ≤20 字 / 正文 100-200 字 / 4-5 个话题 / 结尾软引导），
发之前再搜一次该行业最近爆款确认结构没跑偏。每个行业给出 3 个标题备选 + 1 套正文骨架 +
2 条截流话术。禁止同一账号连续两篇同结构。

通用公式：**共鸣开场（讲真实的累/痛点）→ 转折（被带去/偶然发现/踩坑后）→ 1-2 个真实细节
→ 轻带店 + 软引导（"坐标XX，私我发位置"）→ 4-5 个话题**。

---

## 1. 商K / 商务KTV / 高端会所（双流/成都）

- 人群：商务男士 + 组织宴请的行政/销售；痛点：接待没面子、怕踩雷、怕被宰
- 标题备选：`双流请客踩过的坑，我替老板们试过了` / `双流接待客户，终于找到氛围刚好的场子` / `客户来双流，接待终于不头疼了`
- 正文骨架：接待翻车经历（隔音差/货不对板/订不到位）→ 现在固定这家（私密隔音、管家全安排）→ 客户满意 → 坐标私我
- 话题：#成都商务接待 #双流 #商务宴请 #成都探店 #下班后的别样生活
- 截流话术：`我上次去的XX还不错，私我发你细节` / `接待客户真不能将就，这家值得试试`

## 2. 毕业论文 / 论文辅导（虚拟服务）

- 人群：大四/研三学生；痛点：不会写、没人带、时间紧、查重高、怕答辩挂
- 标题备选：`毕业论文开题，差点把自己写emo了` / `文献综述真的不用从零开始写` / `答辩PPT别再做花里胡哨的了`
- 正文骨架：写论文真实崩溃（卡开题/文献一堆/查重红一片）→ 发现方法/模板（框架先搭、文献按主题分类）→ 文末"需要模板评论区扣1/私我领"
- 话题：#毕业论文 #开题报告 #文献综述 #论文答辩 #大学生日常
- 截流话术：`姐妹我整理的模板可以发你一份` / `我当时也卡这，私我发你思路`
- 红线：禁词"代写/包过"，用"辅导/陪跑/模板/修改建议"替代

## 3. 私域资料 / 虚拟项目 / 资料包引流

- 人群：想省事/想学东西的人群；痛点：信息杂、找不到整理好的
- 标题备选：`整理了一晚上，这份XX避坑指南终于齐了` / `XX入门，看这一篇就够了` / `别乱买课，先领这份XX清单`
- 正文骨架：痛点开场（网上资料太乱）→ 我整理了什么（清单/模板/指南，写具体）→ "想要的扣1，我私你"
- 话题：#干货分享 #XX入门 #避坑指南 #资源整理
- 截流话术：`我领到了，确实全，姐妹们冲`（小号配合） / 大号置顶：`评论区扣1自动发`
- 打法：资料里带联系方式；瞬间/群文件发二维码角落图

## 4. 美业（皮肤管理 / 美容 / 轻医美）

- 人群：20-40 岁女性；痛点：烂脸、敏感、被推销办卡
- 标题备选：`换季烂脸，终于找到不推销的店了` / `敏感肌在XX做了一次就回不去了` / `别再乱挤闭口了，先分清你是哪种肤质`
- 正文骨架：皮肤真实困扰（熬夜/换季/爆痘）→ 被朋友带去体验（先检测后操作、不推销）→ 效果细节 → 坐标私我
- 话题：#皮肤管理 #敏感肌 #烂脸救星 #XX探店 #变美日记
- 截流话术：`姐妹我在XX做的，私我发你位置` / `这家先检测再操作，真的不推销`

## 5. 餐饮探店（本地美食）

- 人群：本地吃货 + 聚餐决策者；痛点：怕踩雷、不知道去哪聚
- 标题备选：`XX这家店，朋友吃完连菜单都想抄走` / `藏在XX巷子里的店，人均XX吃到扶墙` / `聚餐别再去网红店排队了`
- 正文骨架：怎么发现的（路过/朋友带）→ 环境+必点菜细节（锅气/分量/价格）→ 适合谁去 → 坐标
- 话题：#XX美食 #本地探店 #聚餐 #周末去哪吃
- 截流话术：`求地址的姐妹多，我统一说下，私我发你` / `我也去了，确实值得跑一趟`

## 6. 家居 / 装修 / 软装

- 人群：装修业主；痛点：预算超、踩坑多、审美难落地
- 标题备选：`装修半年，最不后悔的5个决定` / `XX平小家，这样装显大又耐看` / `装修预算怎么分？先看这篇再动工`
- 正文骨架：装修真实经历（预算/工期/吵架）→ 干货决定（留白/灯光/收纳）→ 避坑点 → 评论区答疑
- 话题：#装修日记 #家居灵感 #软装搭配 #装修避坑 #小家越住越大
- 截流话术：`我家的清单可以分享，私我发你` / `姐妹这个灯哪买的？同求（小号问，大号答）`

## 7. 教育培训（成人/少儿）

- 人群：家长或想提升的成年人；痛点：效果不确定、怕踩坑
- 标题备选：`孩子学XX一年，说说真实感受` / `成人学XX真的有用吗？学了半年说实话` / `选XX机构前，先问清这3个问题`
- 正文骨架：真实经历（为什么学/怎么选/花了多少）→ 效果细节（具体变化）→ 建议（别急着报大课包）→ 评论区答疑
- 话题：#XX教育 #鸡娃日常 #自我提升 #学习日常
- 截流话术：`我家选的这家还不错，私我聊` / `可以先试听再决定，别急着交钱`

## 8. 本地生活（健身 / 瑜伽 / 足疗 / 理发）

- 人群：本地居民；痛点：怕办卡跑路、效果差
- 标题备选：`下班后的1小时，我去干了这件事` / `XX体验了一次，整个人都松了` / `不办卡不推销的XX，被我找到了`
- 正文骨架：上班累/久坐痛 → 体验过程细节（环境/手法/服务）→ 不推销办卡 → 坐标私我
- 话题：#下班后的别样生活 #XX探店 #放松解压 #本地生活
- 截流话术：`需要的姐妹私我拿位置` / `这家体验感真的不一样，值得去一次`

## 使用流程（每次发布前走一遍，速度优先）

1. 用户说行业 → 查上表拿到人群/痛点/标题/骨架/话题；
2. 快速搜一次该行业最近爆款（标题结构 + 评论区高频问题），选没写过的角度；
3. 拼装文案：标题 ≤20 字、正文 100-200 字、4-5 个话题、结尾"坐标XX，私我发位置"类软引导；
4. `node scripts/xhs-publish.mjs <id> --title "..." --cover "封面文字" --body-file 正文.txt --template random`
   （默认私密；模板随机；封面文字用标题核心词，与标题呼应）；
5. 发布后在笔记管理确认（仅自己可见），记录耗时。
