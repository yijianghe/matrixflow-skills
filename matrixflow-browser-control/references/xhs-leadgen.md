# 小红书矩阵引流陪跑 SOP（SPA / 本地生活 / 到店服务）

本 SOP 是"矩阵高手 / 引流获客"的完整执行手册，所有动作都由浏览器技能执行（`scripts/mf-browser.mjs`、`scripts/xhs-marketing.mjs`、`scripts/human-browse.mjs`），陪跑导师按本手册排期、执行、复盘。

## 0. 账号矩阵规划（先问清楚再动手）

开跑前必须确认：行业/品类、目标城市、门店名称与地址、引流目标（到店/私域）、可用账号数量。

矩阵结构建议（示例 5 个账号）：

| 角色 | 数量 | 用途 |
| --- | --- | --- |
| 主号（品牌） | 1 | 发官方种草笔记、置顶店铺信息 |
| 人设号（体验分享） | 2-3 | 探店/种草/截留，话术差异化 |
| 素人号（评论铺垫） | 1-2 | 只在爆款下评论、点赞收藏 |

每个账号一个独立环境（浏览器窗口）+ 独立指纹/代理，账号之间不互关、不互评、不共用 WiFi/IP。用 `create --count N --prefix xhs` 批量建环境，`open-batch` 批量打开。

---

## 1. 打标签 SOP（养号期，7-14 天）

### 目标
把账号训练成"目标城市 + 健康养生"人群，让推荐流和潜在客户精准触达。

### 关键词矩阵（提前备好 3-5 组）

- 组1 品类：`成都 spa`、`成都按摩`、`成都足疗`
- 组2 功效：`缓解疲劳`、`缓解焦虑`、`肩颈放松`、`助眠`
- 组3 场景：`探店`、`闺蜜`、`加班后`、`情侣`
- 组4 竞争：`古法按摩`、`精油spa`、`泰式按摩`、`日式spa`
- 组5 地域：`成都南门`、`成都高新`、`春熙路按摩`、`成都新店`

### 每日循环（连续 7-14 天）

| 时段 | 动作 | 时长 |
| --- | --- | --- |
| 上午 9:00-10:00 | 打标签 2 组关键词，每组浏览 3-5 篇 | 10-15 分钟 |
| 中午 12:30-13:30 | 打标签 1-2 组关键词 | 5-10 分钟 |
| 晚上 20:00-21:30 | 打标签 2 组 + 刷首页推荐 10 分钟 | 15-20 分钟 |

每天合计：**4-6 组关键词、12-20 篇浏览**，单篇停留 30-90 秒（随机），每 3-4 篇做一次互动（点赞/收藏/关注作者，比例 5:3:1）。

### 执行命令

```bash
node scripts/xhs-marketing.mjs <profileSpec> tag '成都 spa' '缓解焦虑' '探店' --notes 5
```

### 阶段验收
- 第 3-4 天：首页推荐开始出现 spa/按摩相关；
- 第 7 天：能刷到竞品爆款 = 标签基本成型；
- 第 7-14 天：可逐步加入评论/点赞竞品笔记（浅互动）。

### 注意事项
- 新号前 3 天**只浏览不评论**；
- 浏览节奏必须随机（脚本已内置随机停留）；
- 不搜索自己门店名（避免提前暴露商业意图）。

## 2. 评论截留 SOP（养号第 3 天后开启）

### 每日上限与节奏

- **每天 2-3 条，最多不超过 3 条**；
- 每条间隔 ≥ 1 小时，分散到上午/下午/晚上；
- 同一条话术不重复使用，同一条笔记只截一次。

### 选笔记标准（用 pick 排序后人工筛）

- 点赞 ≥ 500（优先 ≥ 1000）；
- 标题含目标城市/区域（本地相关）；
- 评论数活跃（≥ 50）；
- 发布时间 1-30 天内；
- 排除品牌方自己的广告笔记（评论容易被删）。

### 话术规则（不能太刻意）

1. **字数 20-60 字**，像随手写的心得；
2. **结构**：一句经历/场景 + 一句体验细节 + 一句轻推荐/引导；
3. **禁止**：硬广词（"加V""微信""优惠"）、同文案刷屏、带链接；
4. **引导私信**用软表达：`需要的姐妹私我拿地址～`；
5. 每 5 条里至少 3 条是"互动型"（只是认同/提问），只有 2 条是"种草型"。

### 话术模板库（每次换着组合）

- 体验式：`上周末去{地点}那家{品类}试了一下，{细节}，{人群}可以冲！`
- 闺蜜式：`跟闺蜜去的，{细节}，整个人都松了，成都姐妹可以冲！`
- 新店式：`新店真的有惊喜，去了两次了，{功效}真的有用，需要的姐妹私我拿地址～`
- 提问式（互动铺垫）：`姐妹这家在哪啊，最近正好想找一家`
- 认同式：`同感！这家手法真的可以，下次还去`

细节词库：环境安静 / 手法专业 / 精油好闻 / 泡澡舒服 / 服务贴心 / 性价比高 / 缓解焦虑 / 助眠。

### 执行命令

```bash
node scripts/xhs-marketing.mjs <profileSpec> intercept '成都 spa' --title '花小钱可以呆一整天' --comment '<话术>'
```

### 风控信号（立即降频）
- 评论提交后列表不显示 = 被拦截 → 停 2-3 天，只浏览；
- 提示"操作频繁" → 当天停止；
- 评论被删除/账号被限制 → 停止截留，回养号。

## 3. 发笔记 SOP（养号第 10 天后，权重足够再发）

### 第一步：参考爆款（发前必做）

用 `pick` 拉出目标关键词 Top 10-15 篇爆款，分析：

- 标题结构（数字/场景/悬念/功效四选二以上）；
- 封面风格（实拍/大字/对比）；
- 标签组合（前 3 个标签是什么）；
- 评论区高频问题（用户真正关心什么）。

```bash
node scripts/xhs-marketing.mjs <profileSpec> pick '成都 spa' '成都按摩' --top 10
```

### 第二步：改写（禁止抄袭）

- 标题：参照 3 篇爆款结构，改写 3 个备选（数字+场景+悬念）；
- 正文：150-300 字，流程化（环境 → 项目/服务 → 感受 → 价格/位置 → 引导）；
- 图片：6-9 张（环境实拍 + 项目 + 前后对比 + 门头）；
- 标签：5-8 个（2 个大词 + 3 个垂类 + 2 个地域）；
- 定位：加门店位置标签。

### 种草文案风格规范（共鸣体，参考 20 个爆款总结）

**核心：不要像广告，要像"有同样疲惫的普通人"在说话。**

标题公式（三选一，避免"安利/冲/推荐"类广告词）：
- 痛点共鸣：`上班第5年，我的肩颈好像提前退休了`
- 场景共鸣：`双流打工人的周五，终于找到充电的地方`
- 反套路：`不推销不办卡，沉浸式躺平太治愈了` / `谁懂啊，按到肩颈那一下差点睡着`

正文结构（150-300 字）：
1. 共鸣开场：讲真实的累（加班/肩颈硬/睡不着/头昏脑涨），不急着提店；
2. 情绪转折：被朋友拉去/偶然发现 → "没抱期待，结果……"；
3. 细节体验：只写 1-2 个真实瞬间（"按到肩颈那一下差点睡着""回家躺下就睡着"）；
4. 结尾轻带店 + 软引导：`这家店不推销不办卡，安安静静按完就走` + `坐标双流，具体位置私我发你～`。

图片：优先"文字卡片图"（大字共鸣文案 + 干净背景），比实拍更有传播力；实拍图作为补充。

爆款参考（成都 spa/按摩，点赞 100-1600）：南门花小钱呆一天、泡泡浴值得来一趟、不推销不办卡躺平、没去巴厘岛就成都南门、明星同款泰式。评论区高频情绪词：累、需要放松、马杀鸡、哪家、多少钱——内容要接住这些词。

### 第三步：发布节奏

- 每周 2-3 篇，间隔 ≥ 2 天；
- 最佳时段：工作日 20:00-22:00、周末 10:00-12:00 / 16:00-18:00；
- 发布后 1 小时内：回复评论、给笔记点 2-3 个收藏；
- 发布 3 天后数据差（< 100 曝光）：停发，回打标签。

### 发布执行

用浏览器手动发布（登录状态下的创作者中心），或通过 `navigate` 到发布页 + `type`/`click` 操作；技能提供 `eval`/`run` 可辅助批量整理文案。

## 4. 矩阵轮换与复盘

### 每日轮换

- 主号只发笔记、不截留；
- 人设号每天截留 1 条 + 打标签 2 组；
- 素人号每天截留 1-2 条，只发评论不发文；
- 每个账号操作间隔 ≥ 30 分钟（避免同 IP 频率特征，配合指纹/代理更稳）。

### 每周复盘表

| 指标 | 记录 | 目标 |
| --- | --- | --- |
| 打标签篇数 | 每天 12-20 | ≥ 80/周 |
| 截留条数 | 每天 2-3 | 14-21/周 |
| 评论可见率 | 提交后列表可见比例 | ≥ 70% |
| 私信咨询数 | 每周统计 | 稳定上升 |
| 笔记曝光 | 发布后 3 天 | ≥ 1000 再加大投入 |

### 调整策略

- 截留可见率低 → 降频、换话术、回养号；
- 咨询多但到店少 → 优化引导话术（加"离你近/今天预约"类）；
- 某类笔记曝光高 → 复制该类结构，加大该关键词投入。

---

## 5. 风控红线（一票否决）

- 新号前 3 天不评论；
- 同话术不重复、同笔记不二次截留；
- 不刷赞刷评论、不互关矩阵号；
- 评论区不出现手机号/微信号/二维码；
- 每日截留 > 5 条 = 高危，立即停止。

---

## 6. 与浏览器的衔接

所有动作都由浏览器技能执行：

- 建号：`create --count N --prefix xhs` + `open-batch`
- 打标签：`xhs-marketing.mjs tag`
- 选爆款：`xhs-marketing.mjs pick`
- 截留：`xhs-marketing.mjs intercept`
- 真人浏览：`human-browse.mjs`
- 多步组合：`mf-browser.mjs run`

陪跑导师执行 SOP 时：先问清矩阵规模与门店信息 → 给出 7/14 天排期表 → 每天按 SOP 执行并输出进度 → 每周复盘调整。
