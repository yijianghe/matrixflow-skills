# 小红书 SPA / 本地生活 种草引流陪跑手册

面向“到店服务型”商家（SPA、按摩、足疗、美容、美发等）的小红书种草引流完整打法。陪跑导师按本手册指导账号，脚本负责执行（见 `scripts/xhs-marketing.mjs`）。

## 1. 账号定位与打标签

目标：让平台把账号识别为“成都本地生活 / 健康养生”兴趣用户，从而把同赛道笔记和潜在客户推给账号。

打标签关键词矩阵（覆盖品类 / 功效 / 场景）：

- 品类词：`成都 spa`、`成都按摩`、`成都足疗`、`精油spa`、`古法按摩`
- 功效词：`缓解疲劳`、`缓解焦虑`、`肩颈放松`、`助眠`
- 场景词：`加班后`、`探店`、`情侣约会`、`闺蜜`

动作：对每个关键词搜索并真人式浏览 3-5 篇（随机停留、滚动、看评论区），每天 1-2 组，持续 3-5 天。用 `tag` 动作。

## 2. 选爆款（截留目标筛选）

用 `pick` 动作按点赞数排序，再人工筛选：

- 高赞（500+ 优先，1000+ 更好）；
- 成都本地相关（标题含城市 / 区域，如“成都南门”“成都新开的”）；
- 评论区活跃（看评论数，越活跃曝光越高）；
- 发布时间新（1-30 天内的笔记权重高）。

优先级示例：`成都南门花小钱可以呆一整天`（1584赞）> `为了这家泡泡浴你值得来一趟成都`（540赞）> `新开的缓解焦虑`（398赞）。

## 3. 评论区截留（种草话术）

原则：像真实用户体验分享，不像广告；首段经历 + 一句推荐 + 引导私信；每条话术不同，避免重复。

话术模板（按场景套用）：

- 体验式：`上周末去{地点}那家{品类}试了一下，{体验细节}，{人群}可以冲！`
- 闺蜜式：`跟闺蜜去的，{体验细节}，整个人都松了，成都姐妹可以冲！`
- 新店式：`新店真的有惊喜，去了两次了，{功效}真的有用，需要的姐妹私我拿地址～`
- 平价式：`{价格}就能体验，环境比想象中好，性价比真的高，推荐！`

细节库：环境安静 / 手法专业 / 精油好闻 / 泡澡舒服 / 服务贴心 / 性价比高 / 缓解焦虑 / 助眠。

节奏：同一账号每日 2-3 条，间隔 1-2 小时，换不同笔记和话术；连续多条会触发风控。

## 4. 自有内容种草（进阶）

账号养到一定权重后，发布自己的探店/种草笔记（用 `发布` 动作或手动）：

- 标题：数字 + 场景 + 悬念（`成都姐妹快冲！这家SPA我可以去一百次`）；
- 封面：实拍环境/项目图，大字标题；
- 正文：体验过程（环境 → 服务 → 感受）+ 1-2 张图 + 位置标签；
- 评论区引导：置顶自己店铺信息/预约方式。

## 5. 数据跟踪与复盘

- 每天记录：浏览笔记数、点赞/收藏/评论互动数、发布评论数、私信咨询数；
- 判断账号权重：评论是否被平台拦截（输入后不显示 = 被风控，先养号）；
- 调整：被拦截就降低频率、换话术、多打标签；爆款方向看互动数据。

## 6. 风控红线

- 新号不截留、先养 3-5 天；
- 同一条话术不重复使用；
- 不刷屏、不批量点赞评论；
- 引导私信用“私我拿地址”等软表达，不在评论区留电话/微信（会被删+降权）。
