# 全行业小红书引流陪跑 SOP 生成框架（v1，2026-08-05）

用户只要说一句"我是做 XX 的"，就按本框架**现场生成**整套 7/14 天引流转化 SOP：
养号 → 打标签 → 爆款选题 → 发笔记 → 评论区截流 → 私信截流 → 时间排期 → 风控。
生成后直接用浏览器技能执行：`xhs-feed-browse.mjs`（养号循环）、`xhs-marketing.mjs`（打标签/选爆款/截留）、`xhs-publish-native-text-to-image.md`（发笔记）。

**铁律：先填"行业画像五要素"，再套"九步模板"，禁止不调研就直接给模板。**

## 2. 通用九步 SOP 模板

### 第 1 步 账号矩阵（先定角色，再开窗口）

| 角色 | 数量 | 职责 |
| --- | --- | --- |
| 主号（品牌/专家人设） | 1 | 发专业内容、置顶转化笔记、不亲自截流 |
| 人设号（体验/学长学姐） | 2-3 | 探店/经验分享/种草，话术差异化 |
| 素人号（评论铺垫） | 1-2 | 只在爆款评论区做自然承接，不进主页导流 |

一个角色一个独立环境（MatrixFlow 窗口）+ 独立指纹/代理。用 `create --count N --prefix <行业>` 批量建，`open-batch` 批量开。

### 第 2 步 打标签（7-14 天，把号喂成"目标人群"）

关键词矩阵 = 品类词 + 功效词 + 场景词 + 地域词 + 竞争词（每类 3-5 个，从五要素表里取）。
每天 4-6 组关键词、12-20 篇浏览；单篇停留 30-90 秒随机；每 3-4 篇互动一次（赞:藏:评 ≈ 5:3:1）。
执行：`node scripts/xhs-marketing.mjs <id> tag '词1' '词2' ... --notes 5`

### 第 3 步 养号（真人行为，杜绝机器感）

执行 `xhs-feed-browse.mjs`（v2 已内置）：
- 详情打开后只滚右侧内容面板 `.note-scroller`，背景瀑布流不动；
- 图文停留 30-45 秒随机，视频按播放进度等；
- 多图切图 1-3 次带验证、随机展开二级/三级评论；
- 点赞 35% / 收藏 20% 概率，先查状态再点，数字 +1 才算成功；
- 每日上限：赞 ≤ 30、藏 ≤ 20、评 ≤ 15，新号前 3 天不评论。

### 第 4 步 爆款选题（发笔记前必做，参考 20 篇）

用 `xhs-marketing.mjs pick` 拉目标关键词 Top 10-15 篇，拆 4 件事：
标题结构（数字/场景/悬念/功效四选二以上）、封面风格、前 3 个标签、评论区高频问题（用户真正在意什么）。
选题方向必须覆盖：**痛点共鸣型 + 干货工具型 + 避坑型 + 场景记录型** 四种，不要只发一种。

### 第 5 步 发笔记（共鸣体文案，禁止广告腔）

标题公式（三选一）：
- 痛点共鸣：`上班第5年，我的肩颈好像提前退休了`
- 场景共鸣：`双流打工人的周五，终于找到充电的地方`
- 反套路：`不推销不办卡，沉浸式躺平太治愈了`

正文 150-300 字结构：共鸣开场 → 情绪转折 → 1-2 个真实细节 → 结尾轻带店 + 软引导（`坐标XX，具体位置私我发你～`）。
图片 6-9 张或文字卡片图（大字共鸣文案 + 干净背景）。发布节奏：每周 2-3 篇、间隔 ≥ 2 天、发布后 1 小时回评。

### 第 6 步 评论区截流（在同行爆款下捞精准客）

选笔记标准：点赞 ≥ 500、评论活跃 ≥ 50、发布时间 1-30 天、本地相关、非品牌硬广。
承接动作（**必须用小号，大号不碰**）：
1. 找"求地址/求链接/求推荐"类评论；
2. 小号自然回复：`我买过/我去过，姐妹你私我一下，我发你`（不带敏感词，作者删不掉）；
3. 关键词埋点：`搜'XX'看第一篇就是`（那篇笔记里放转化路径）；
4. 每天 2-3 条上限，间隔 ≥ 1 小时，同一话术不重复。

### 第 7 步 私信截流（承接 + 转化）

核心：**延迟满足 + 制造正当理由，先聊两句再引导，绝不第一句甩微信/链接。**
1. 对方问"怎么买/在哪"→ 先纯客服式回两句（"有的哦，不过颜色不全了，你要哪个呀"）；
2. 建立信任后给正当理由："点我瞬间看细节图/回个 1 系统自动发你资料"；
3. 链接/二维码放自动回复、瞬间图片角落或置顶笔记，不直接出现在正文/私信第一句；
4. 转化路径：评论区种草 → 主页置顶/收藏夹（放门店信息）→ 私信承接；
5. 每日引流控制在 50 人以内，多备小号轮换。

### 第 8 步 时间排期（真人逻辑：碎片时间 + 间隔）

真人不是"上午 9 点准时开刷"，而是早中晚碎片时间：7:30-8:30 / 12:30-13:30 / 20:00-21:30 三小段，每段 10-20 分钟，动作间隔 3-15 秒随机，同账号操作间隔 ≥ 30 分钟。

**7 天冷启动模板**（示例行业可替换关键词）：
| 天数 | 上午 | 中午 | 晚上 |
| --- | --- | --- | --- |
| D1-D3 | 只刷首页/搜索 2 组词，不评论不互动过频 | 浏览 3-5 篇 | 养号 10 分钟 |
| D4-D5 | 打标签 2 组 + 开始点赞收藏 | 浏览 | 养号 + 选 5 篇爆款做选题分析 |
| D6-D7 | 打标签 + 准备首篇笔记 | 首篇笔记发布（20:00 后） | 回评 + 小号评论区铺垫 |
| D8-D14 | 每周 2-3 篇笔记 | 评论区截流 1-2 条 | 私信承接 + 复盘数据 |

### 第 9 步 风控红线（一票否决）

- 新号前 3 天不评论；不刷赞刷评、不互关矩阵号；
- 评论区/私信不出现手机号、微信号、二维码直接露出；
- 同话术不重复、同笔记不二次截留；每日截留 > 5 条 = 高危；
- 秒赞秒评是雷区（必须先完整看完再互动）；2026 用户反感 AI 腔话术，必须真实口语化；
- 出现"操作频繁/评论不显示/被删"→ 立即降频回养号。

## 3. 评论区"留钩子"识别清单（看到就懂同行怎么截的）

下面的评论形态 = 别人在留钩子，看到后不要直接撞车，改用差异化话术承接：

| 钩子形态 | 例子 | 目的 |
| --- | --- | --- |
| 求地址/求链接 | `姐妹这家在哪呀` / `求链接` | 触发式提问，等正主或截流号接 |
| 私我/私你 | `姐妹私我一下，我发你` | 把流量导向私信 |
| 扣1/暗号 | `需要的宝子评论区扣1` | 筛选意向 + 自动回复发资料 |
| 关键词埋点 | `搜"XX"看第一篇就是` | 导到自己的主页/置顶笔记 |
| 双簧 | A：`我用过，靠谱！` B：`姐妹求带！` | 自导自演制造真实感 |
| 置顶评论 | 楼中楼持续更新资料/案例 | 长期占位截流 |
| 反问引导 | `你们一般预算是多少` | 收集意向，私信跟进 |

识别后执行：小号在**评论数活跃**的笔记下自然承接（一天 2-3 条），大号只在自己的笔记评论区做置顶引导。

## 4. 已吸收行业案例库（喂过的"饭"）

### 4.1 SPA / 本地生活 / 到店服务（完整版见 xhs-leadgen.md）
- 人群：25-40 岁女性；关键词：成都spa、缓解疲劳、探店；
- 爆款方向：南门花小钱呆一天 / 不推销不办卡躺平 / 明星同款泰式；
- 截流话术：`上周末去试了一下，环境舒服手法专业，需要的姐妹私我拿地址～`。

### 4.2 商K / 商务KTV / 高端会所
- 人群：商务男士 + 组织宴请的行政/销售/采购；
- 痛点：接待没面子、怕踩雷、怕被宰、要私密有排面；
- 内容切入：**不打"KTV 广告"，打"商务接待场景"**——商务宴请攻略、包间环境探店、接待流程避坑、人均区间明示（如"人均300+，适合商务宴请和纪念日"用价格筛客）；
- 标题：`XX商务宴请不踩雷指南` / `接待客户终于有地方去了` / `这家会所的环境是真的能撑场面`；
- 关键点：本地同城词（城市名+商务局/宴请）+ 图片重环境私密感 + 评论区引导"私我发档期/位置"；
- 截流：在"XX 宴请/聚会去哪"类笔记下小号接 `我上次去的XX还不错，私我发你细节`。

### 4.3 大学生毕业论文 / 论文辅导（虚拟服务）
- 人群：大四/研三学生；痛点：不会写、没人带、时间紧、查重高、怕答辩挂；
- 人设三选一：学术导师型（权威）/ 学长学姐型（亲和）/ 论文急救专家（实用）；
- 爆款方向：开题报告模板、文献综述怎么写、查重降重技巧、答辩PPT模板、时间规划表；
- 引流打法：干货笔记 + 文末"需要 XX 模板评论区扣1/私我领"→ 小号回复"已安排发送，注意查收私信"；
- 话术禁词：代写、包过（高危），用"辅导、陪跑、答疑、模板、修改建议"替代；
- 转化：免费模板筛精准客 → 私信报价1V1辅导（行业参考：转化率 5% 左右，客单几百到几千）。

### 4.4 私域粉 / 资料包 / 虚拟项目引流
- 打法：纯资料/工具型笔记（模板、清单、避坑指南）吸精准粉 → 自动回复发资料 → 资料里带联系方式；
- 钩子设计：`整理了一份《XX避坑指南》，想要的扣1，我私你`；
- 瞬间/群聊：瞬间发"群文件有详细教程"图片角落放码；群聊发文件命名"联系客服.png"；
- 三级互动体系：主动引导层（扣1话术）+ 问题解答层（预设 20 个 Q&A 模拟真实对话）+ 口碑营造层（每周 3 条好评置顶、负面 30 分钟内私信处理）；
- 注意：同文案刷屏必挂，话术按行业换着组合。

## 5. 话术库（通用，按行业换词）

### 评论截流（小号用，20-60 字，像随手心得）
- 体验式：`上周末去{地点}那家试了一下，{细节}，{人群}可以冲！`
- 闺蜜式：`跟闺蜜去的，{细节}，整个人都松了，需要的姐妹私我拿地址～`
- 提问式（互动铺垫）：`姐妹这家在哪啊，最近正好想找一家`
- 认同式：`同感！这家真的可以，下次还去`

### 私信承接（先聊后导，禁止第一句甩微信）
- 第一句（纯客服）：`有的哦，你要哪个呀？`
- 第二句（正当理由）：`这里发图好模糊，你点我瞬间看细节图，那个是原图`
- 资料钩子：`我发你一份整理好的资料/指南，回个 1，系统自动发你`
- 主页引导：`主页置顶第一条有完整信息，你点开看下～`
